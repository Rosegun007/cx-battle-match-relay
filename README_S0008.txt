CX对战联机服务器 S0008
配套客户端：S0008-0001-1。
本包是代码交付，未替您部署线上服务。
沿用既有 Worker 名称、CX_MATCH_HUB 绑定、CXMatchHub 类和 v1 migration；请使用原部署账号与项目配置发布。
如使用 Wrangler：在本目录安装 package.json 中依赖后执行 npm run deploy。
若您实际部署使用额外域名或账号配置，请保留自己的配置。

协议：CX_ORDERED_RELAY_S0008_V1；本版本不兼容 S0007 客户端的联机协议。
先更新服务器，再让双方使用新客户端。已有旧局不会跨协议迁移。
健康检查输出 serviceVersion=S0008、tickRate=30 和 parameters。

行为：部署即时转发给对手，对手接收后即时 ACK。服务器只检查传输信封、房间归属和时限，不承担战斗规则/能量/外挂校验。
战斗心跳 1 秒；Waiting 心跳 10 秒。连接超时与操作超时分别处理。
服务器接收部署时，要求 tick_server+6 <= tick_action+windup_ticks-2。
失去连接、超时或同步失败后通知双方分别转本地人机续战；已经结束的战斗由客户端标记未确认，不复活战斗。
对端已断网时无法保证立即送达，失联客户端由自身超时检测完成接管。
全部参数为首轮测试值，详见客户端自审与验收说明。
